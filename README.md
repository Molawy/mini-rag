# mini-rag application:

This is a minimial implementation of the RAG model for question answering.

## Requirements
 -python 3.8 or later
#### Intsall Python miniconda

 1)Download and install miniconda from [here](https://www.anaconda.com/download/success?reg=skipped-miniconda)

2)Create a new environment using the following command:
```bash
$ conda create -n mini-rag python =3.8
```
3)Activate the environment:
```bash
$ conda activate mini-rag
```
